# Changelog

## 2.0.0 — 2026-10-30

First release as **Timetabs**.

- Command bar (⌥⇧P): type `1 30m review CR`, `fri 9`, `every 1h`, `done`, `snooze 15m`.
- Priorities P1–P3 with optional colored tab groups that never touch your own groups.
- Reminders: one-off, repeating, plain (no priority), on a tab, several tabs, or a group.
- Overdue badge, Now list, pop-up window alerts, per-priority chimes.
- Reminders that fire together arrive as one alert.
- Shortcuts: ⌥⇧P command bar, ⌥⇧N most urgent, ⌥⇧S snooze overdue, ⌥⇧1 mark P1.
